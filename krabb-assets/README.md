# Krabb Assets

Brand assets for Krabb and the krabblab organization. SVG files are the sources; PNG files
are exports for places that need raster images.

## Krabb

| File | Use |
| --- | --- |
| `krabb/krabb-logo-on-light.svg` | Logo with wordmark on light backgrounds. |
| `krabb/krabb-logo-on-dark.svg` | Logo with wordmark on dark backgrounds. |
| `krabb/krabb-mark-orange.svg` | Mark alone, orange. |
| `krabb/krabb-mark-slate.svg` | Mark alone, slate. |
| `krabb/krabb-mark-white.svg` | Mark alone, off-white. |
| `krabb/krabb-app-icon.svg`, `krabb/krabb-app-icon-512.png` | Rounded application icon. |
| `krabb/krabb-social-preview-1280x640.png` | Repository social preview, slate. |
| `krabb/krabb-social-preview-orange-1280x640.png` | Repository social preview, orange. |

## Krabblab

| File | Use |
| --- | --- |
| `krabblab/krabblab-logo-on-light.svg` | Organization logo on light backgrounds. |
| `krabblab/krabblab-logo-on-dark.svg` | Organization logo on dark backgrounds. |
| `krabblab/krabblab-avatar.svg`, `krabblab/krabblab-avatar-512.png` | Square avatar, slate. |
| `krabblab/krabblab-avatar-orange.svg`, `krabblab/krabblab-avatar-orange-512.png` | Square avatar, orange. |

## Colors

| Name | Hex |
| --- | --- |
